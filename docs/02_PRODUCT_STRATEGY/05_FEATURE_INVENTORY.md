## Prioritization and acceptance
Phase labels are hypotheses, not contractual dates. Phase 1 includes only features needed to complete and support a coherent managed loop; each action requires role, data, explicit state, error, audit and test specification. Optional proxy bidding, anti-sniping, deposit and credit remain disabled until policy is approved. A listing in this inventory is not proof of an implemented or approved feature.
